# apples
New Neocities layout.

**live demo whenever neocities delays to update:** [https://apples-seven.vercel.app](https://apples-seven.vercel.app/)

## what it is
Another personal website that now expands on more unexplored topics, with a palette I picked from Coolors and two fonts I got from Google Fonts.

## how I made it
- React + Vite, plain CSS plus TailwindCSS
- started from the Snowglobe React + Better Web Design guide,
  then changed: layout, sequence, and additional buttons
- my own design guide is in DESIGN.md

## what I learned / struggled with
- the website went down five times and i forgot how to read js
- adapting vanilla HTML/CSS/JS structures to this
- making a play/pause button
- getting images to look proportionate
- editing font-size with tailwindcss

## run it yourself
```
npm install
npm run dev
```
